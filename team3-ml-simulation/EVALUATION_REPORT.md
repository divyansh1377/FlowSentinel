## 2. Dataset & Feature Definitions

### 2.1 Training Dataset Composition
- **Total Generated Samples**: 20,000 synthetic physics-derived records (`data_generator.py`).
- **Feature Set**:
  1. `distance_cm`: Ultrasonic air gap clearance ($0.0 - 120.0\text{ cm}$).
  2. `weight_kg`: HX711 Load Cell mass burden ($0.0 - 1500.0\text{ kg}$).
  3. `vibration_g`: MPU6050 3-Axis total acceleration RMS ($0.01 - 15.0\text{ G}$).
  4. `material_flow_rate_tph`: Instantaneous conveyor feed throughput ($0.0 - 500.0\text{ TPH}$).
- **Class Breakdown**:
  - `0 (NORMAL)`: 65.0% (13,000 samples)
  - `1 (WARNING)`: 22.0% (4,400 samples)
  - `2 (BLOCKAGE)`: 13.0% (2,600 samples)
  - `Out-of-Distribution Anomalies`: 5.0% (1,000 samples)

## 6. Sub-Component Inference Latency Profiling

Latency profiling over 2,000 warm executions on Python 3.9:

| Component / Pipeline Step | Mean Time (ms) | Percentage of Total |
| :--- | :--- | :--- |
| **Input Extraction & Memory Alignment** | $0.002\text{ ms}$ | $0.01\%$ |
| **Temporal Buffer Update ($dW/dt$, $d(\text{dist})/dt$)** | $0.030\text{ ms}$ | $0.18\%$ |
| **Inline Vector Scaling (`(x - mean) * scale_inv`)** | $0.005\text{ ms}$ | $0.03\%$ |
| **Random Forest Prediction (`predict_proba`)** | $12.600\text{ ms}$ | $76.58\%$ |
| **Isolation Forest (`decision_function`)** | $3.800\text{ ms}$ | $23.09\%$ |

| **Diagnostic Classification & Output Dict** | $0.009\text{ ms}$ | $0.05\%$ |

### Bottleneck Analysis:
The primary bottleneck ($99.67\%$ of execution time) resides entirely inside `scikit-learn`'s single-sample C-API call overhead when dispatching tree traversals for $1 \times 4$ NumPy arrays.

> [!WARNING]
> **Target Status**: The achieved mean warm latency ($16.453\text{ ms}$) is slightly above the strict $15.0\text{ ms}$ project target. To achieve sub-5ms latency without reducing tree estimators further, the models should be exported to ONNX format (`onnxruntime`).
